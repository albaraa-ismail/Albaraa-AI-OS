# Albaraa-AI-OS
**منظومة تشغيل ذكية متعددة الوكلاء (Multi-Agent AI Operating System)** — مشروع التخرج

نظام تشغيل متكامل للذكاء الاصطناعي يعتمد على معمارية معيارية مرنة (Modular Multi-Agent Architecture) تجمع بين التنسيق الذكي للمهام، والأمن السيبراني الاستباقي، والمعالجة متعددة الوسائط، وتعلّم الآلة والتعلّم المعزّز، والرصد اللحظي، لأتمتة العمليات المعقدة واتخاذ القرارات المدعومة بالبيانات.

---

## البنية المعمارية للمنظومة (System Architecture)

ينقسم النظام إلى ست طبقات برمجية مترابطة عبر ناقل أحداث مركزي:

### 1. النواة والتنسيق المركزي (`core/`)
* **`core/event_bus.py` — ناقل الأحداث المركزي:** ربط الوحدات غير المتزامن *(الخوارزميات والمنطق + البرمجة بالبايثون)*.
* **`core/orchestrator.py` — محرك التنسيق وإدارة المهام:** تحليل الطلبات وتوزيعها ديناميكياً *(النظم الخبيرة)*.
* **`core/failover_cache.py` — محرك التعافي والتخزين المؤقت الذكي:** ضمان استمرارية الخدمة وتسريع الاستجابة *(تطبيقات الحاسب المتقدمة + الخوارزميات + التعلم العميق + أساسيات قواعد البيانات)*.
* **`core/core_ai.py` & `core/auto_scheduler.py`:** بوابة النماذج السحابية المتعددة والمجدول الذاتي للمهام الدورية.

### 2. الأمن السيبراني والحوكمة (`security/`)
* **`security/iam_gateway.py` — بوابة الهوية وعزل البيانات:** إدارة الصلاحيات وفصل بيانات المستفيدين *(تطبيقات الحاسب المتقدمة + البرمجة بالبايثون + أساسيات قواعد البيانات)*.
* **`security/safe_guard.py` — درع الحماية السيبراني:** كشف ومنع محاولات الاختراق والحقن النصي *(الأمن السيبراني بالذكاء الاصطناعي)*.
* **`security/vault_masking.py` — قبو الأسرار وإخفاء البيانات الحساسة:** تشفير المفاتيح وحماية الخصوصية تلقائياً *(الأمن السيبراني بالذكاء الاصطناعي)*.
* **`security/audit_ledger.py` — سجل التدقيق الجنائي:** سلسلة تجزئة غير قابلة للتعديل لتتبع العمليات *(موضوعات مختارة + أساسيات قواعد البيانات)*.

### 3. المعالجة متعددة الوسائط واللغات (`multimodal/`)
* **`multimodal/arabic_nlp.py` — معالجة اللهجات وتحسين الأسلوب:** تطبيع اللهجة السعودية وصقل الصياغة البشرية *(معالجة اللغات الطبيعية والصورة الرقمية + لغة إنجليزية)*.
* **`multimodal/media_reader.py` — فهم البصمات الصوتية:** تفريغ وتحليل الرسائل الصوتية بدقة *(التعلم العميق + معالجة اللغات الطبيعية)*.
* **`multimodal/media_maker.py` — محرك الصوت السعودي البشري:** توليد مخرجات صوتية طبيعية ومستنسخة *(معالجة اللغات الطبيعية والصورة الرقمية)*.
* **`multimodal/media_vision.py` — قراءة الصور والوثائق:** استخراج وتحليل البيانات من الصور وملفات PDF و Word و Excel *(معالجة اللغات الطبيعية والصورة الرقمية)*.
* **`multimodal/office_tools.py` — الرسوم البيانية والتقارير التنفيذية:** توليد لوحات القيادة والملفات المؤسسية تلقائياً *(علم البيانات وتحليلها)*.

### 4. الذكاء الاصطناعي والذاكرة (`intelligence/`)
* **`intelligence/ml_intent_anomaly.py` — مصنف النوايا وكشف الشذوذ:** تصنيف الطلبات ورصد الأنماط غير الطبيعية *(تعلّم الآلة)*.
* **`intelligence/rl_router.py` — مسرّع التوجيه الذكي:** تحسين اختيار مسار التنفيذ ذاتياً *(التعلم المعزّز)*.
* **`intelligence/research_agent.py` — التفكير العميق ومدقق المراجع:** الاستقصاء الحي وتوثيق المصادر *(خوارزميات الذكاء الاصطناعي + النظم الخبيرة)*.
* **`intelligence/memory_engine.py` — الذاكرة الدلالية والبحث الهجين:** استرجاع السياق بالدمج بين التطابق اللفظي والدلالي *(خوارزميات البحث + أساسيات قواعد البيانات)*.
* **`intelligence/learning_agent.py` & `intelligence/builder_agent.py`:** تدقيق جودة المخرجات والهندسة البرمجية.

### 5. القنوات الموحدة وجسر الروبوتية (`channels/`)
* **`whatsapp_server.py` — بوابة القنوات الموحدة:** واجهة تفاعلية موحدة للويب وواتساب ولوحات القيادة الحية *(مقدمة في تطبيقات الحاسب + تطبيقات متقدمة)*.
* **`channels/robotics_bridge.py` — بروتوكول الربط الشامل وجسر الروبوتية:** تبادل القياسات وأوامر التحكم الآمنة *(الروبوتية + خوارزميات الذكاء الاصطناعي)*.

### 6. الرصد والتقييم والمقارنات المعيارية (`telemetry/`)
* **`telemetry/evolution_engine.py` — مقياس تطور المستفيدين والتعلم من التقييم:** قياس الأثر وتحسين الأداء من التغذية الراجعة *(التعلم المعزّز + علم البيانات وتحليلها)*.
* **`telemetry/realtime_monitor.py` — نظام الرصد اللحظي:** تتبع زمن الاستجابة ومعدلات الإنجاز *(علم البيانات وتحليلها + الخوارزميات)*.
* **`telemetry/benchmark_lab.py` — مختبر التجارب والمقارنات المعيارية:** اختبارات آلية لقياس دقة وكفاءة الوحدات *(علم البيانات وتحليلها + مقدمة في الذكاء الاصطناعي)*.

## التشغيل السريع (Deployment)

النظام مبني بلغة **Python** ويعمل كخادم سحابي متكامل (Flask + Gunicorn):

```bash
pip install -r requirements.txt
gunicorn whatsapp_server:app --bind 0.0.0.0:10000
```

### متغيرات البيئة المطلوبة (Environment Variables)
* `SUPABASE_URL` & `SUPABASE_KEY`: للذاكرة الدلالية وسجلات الأداء والتدقيق.
* `GROQ_API_KEY` / `GEMINI_API_KEY` / `SAMBANOVA_API_KEY`: لمحركات الذكاء الاصطناعي والرؤية والصوت.
* `GREEN_ID_INSTANCE` & `GREEN_API_TOKEN`: للربط المباشر مع واتساب.
* `ADMIN_PHONE`: رقم المشرف المعتمد لإدارة النظام.
